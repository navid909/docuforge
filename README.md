# DocuForge — Free Online PDF & Document Tools

Free online PDF and document tools with premium upgrades and ads.

## Quick Start — Local Development

### Prerequisites

- Python 3.11+
- Node.js 18+
- tesseract-ocr, poppler-utils (for PDF/image tools)
- System libs: `apt install tesseract-ocr poppler-utils libtesseract-dev`

### Backend

```bash
cd backend

# 1. Create and activate virtual environment
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Install test dependencies (optional but recommended)
pip install -r requirements-tests.txt

# 4. Generate test assets
python tests/generate_test_assets.py

# 5. Start the server
uvicorn main:app --reload --port 8000
```

Backend runs at **http://localhost:8000**. Health check: `curl http://localhost:8000/health`

### Frontend

```bash
cd frontend

# 1. Install dependencies
npm install

# 2. Copy env template and set backend URL
cp .env.example .env.local
# Edit .env.local: NEXT_PUBLIC_BACKEND_URL=http://localhost:8000

# 3. Start dev server
npm run dev
```

Frontend runs at **http://localhost:3000**.

### Run Acceptance Tests

Tests require the backend to be running on `http://localhost:8000`.

```bash
cd backend

# Run all sprint tests (1-6)
python tests/test_sprint1.py   # Sprint 1: Infrastructure
python tests/test_sprint2.py   # Sprint 2: Core PDF tools
python tests/test_sprint3.py   # Sprint 3: PDF utilities (merge/split/compress/OCR)
python tests/test_sprint4.py   # Sprint 4: Auth + rate limiting
python tests/test_sprint5.py   # Sprint 5: Monetization
python tests/test_sprint6.py   # Sprint 6: Launch + load test
```

Or run a single test:
```bash
BACKEND_URL=http://localhost:8000 python tests/test_sprint1.py
```

Each test prints `PASS`/`FAIL` per check and exits with code 0 (all pass) or 1 (any fail).

## API Endpoints

### Tools (POST, requires auth for most)

| Endpoint | Input | Output |
|----------|-------|--------|
| `/tools/pdf-to-word` | PDF file | DOCX file |
| `/tools/pdf-to-excel` | PDF file | XLSX file |
| `/tools/pdf-to-ppt` | PDF file | PPTX file |
| `/tools/docx-to-pdf` | DOCX file | PDF file |
| `/tools/xlsx-to-pdf` | XLSX file | PDF file |
| `/tools/pptx-to-pdf` | PPTX file | PDF file |
| `/tools/image-to-pdf` | JPG/PNG file | PDF file |
| `/tools/pdf-to-images` | PDF file | ZIP of page images |
| `/tools/merge-pdfs` | 2–5 PDF files | Merged PDF file |
| `/tools/split-pdf` | PDF file + `pages` form param | ZIP of split PDFs |
| `/tools/compress-pdf` | PDF file | Compressed PDF file |
| `/tools/ocr-image` | Image file (or scanned PDF) | JSON `{text: "..."}` |

### Auth

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/auth/signup` | POST `?email=` | Create user, return API key |
| `/auth/login` | POST `?email=` | Return API key + premium status |
| `/auth/me` | GET `Authorization: Bearer <key>` | Current user info |

### Premium

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/premium/checkout` | POST `{"plan": "pro"}` | Create Stripe checkout (staging mode) |

### System

| Endpoint | Description |
|----------|-------------|
| `/health` | Health check — returns `{"status": "ok"}` |

### Authorization

All tool endpoints (except health) require `Authorization: Bearer <api_key>` header. Free users are rate-limited to 10 requests/minute. Premium users have no rate limit.

## Deploy

### Backend (Render)

1. Push repo to GitHub
2. Create new **Web Service** on [Render](https://render.com)
3. Connect repo, set root directory to `backend`
4. Build command: `pip install -r requirements.txt`
5. Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
6. Add environment variables:
   ```
   PYTHON_VERSION=3.11.0
   TESSDATA_PREFIX=/usr/share/tesseract-ocr/4.00/tessdata
   ```
7. Deploy

Render blueprint is at `backend/render.yaml` — import it directly on Render.

### Backend (Docker)

```bash
cd backend
docker build -t docuforge .
docker run -p 8000:8000 docuforge
```

The Dockerfile uses a multi-stage build (builder + runtime) with non-root user.

### Backend (VPS — Hetzner CX32)

```bash
# On your VPS (Ubuntu 22.04+)
ssh root@your-server-ip

# Install system dependencies
apt update && apt install -y \
  nodejs npm postgresql redis-server \
  libreoffice imagemagick ffmpeg tesseract-ocr \
  nginx certbot

# Clone repo
git clone https://github.com/your-username/pdf-tools-microsaas.git
cd pdf-tools-microsaas/backend

# Install Python deps
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Create .env.production
cat > .env << 'EOF'
DATABASE_URL="postgresql://docuforge:***@localhost:5432/docuforge"
REDIS_URL="redis://localhost:6379"
NEXTAUTH_SECRET="generated-secret-here"
NEXTAUTH_URL="https://docuforge.app"
STRIPE_SECRET_KEY="sk_live_..."
STRIPE_WEBHOOK_SECRET="whsec_..."
RESEND_API_KEY="re_..."
UPLOAD_DIR="/var/www/docuforge/uploads"
MAX_FILE_SIZE_MB=50
EOF

# Start server (systemd service)
cat > /etc/systemd/system/docuforge.service << 'EOF'
[Unit]
Description=DocuForge Backend
After=network.target

[Service]
Type=simple
User=www-data
WorkingDir=/opt/pdf-tools-microsaas/backend
ExecStart=/opt/pdf-tools-microsaas/backend/.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
EOF

systemctl enable --now docuforge
```

### Frontend (Vercel)

1. Push repo to GitHub
2. Import project on [Vercel](https://vercel.com)
3. Set root directory to `frontend`
4. Add environment variable:
   ```
   NEXT_PUBLIC_BACKEND_URL=https://your-backend.onrender.com
   ```
5. Deploy

Vercel config is at `frontend/vercel.json`.

### Nginx Reverse Proxy (VPS)

```nginx
server {
  listen 80;
  server_name docuforge.app www.docuforge.app;
  return 301 https://$server_name$request_uri;
}

server {
  listen 443 ssl http2;
  server_name docuforge.app www.docuforge.app;

  ssl_certificate /etc/letsencrypt/live/docuforge.app/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/docuforge.app/privkey.pem;

  location / {
    proxy_pass http://localhost:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection 'upgrade';
    proxy_set_header Host $host;
    proxy_cache_bypass $http_upgrade;
  }
}
```

## Stripe Setup

1. Create a Stripe account at [stripe.com](https://stripe.com)
2. Get your webhook secret from the Stripe dashboard
3. Add webhook endpoint: `https://your-backend.onrender.com/webhook/stripe`
4. Set `STRIPE_WEBHOOK_SECRET` environment variable on backend
5. Create checkout sessions with `metadata.api_key` for user tracking

## AdSense

- Replace ad placeholders in frontend with AdSense code
- Ad slots available on: home page, tool pages, pricing, premium
- Free users see ads; premium users get ad-free experience
- Add `data-ad-slot` per page position
